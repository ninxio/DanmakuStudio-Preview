# 隐私与本地数据

## 默认数据来源

应用只使用用户主动选择的本地视频、XML、项目文件，以及用户主动配置的 Emby 服务器。不会自动扫描整个磁盘，也不会把本地媒体上传到项目仓库。

## 项目文件保存

`.danmaku-project.json` 可能包含：

- 媒体文件名、本地路径引用和内容身份摘要；
- 解析后的弹幕条目；
- XML 与参考视频绑定；
- 时间片段、时间映射、同步点、版本差异；
- 禁用弹幕与单条调整；
- 预览和时间轴设置；
- 可审计的验证元数据。

项目不嵌入视频字节。

## 不进入项目文件

- Emby 密码和访问 token；
- 临时播放 URL；
- 视频内容和浏览器对象 URL；
- 安装级 HMAC secret；
- 本机权威撤销注册表；
- 进程原始 stderr 或工具中的敏感参数。

Emby 密码只保存在当前会话内存。非敏感设置保存在 Tauri 应用配置目录；浏览器开发模式使用 localStorage fallback。

## 本机内容存储

桌面版会把用户选择的原始 XML 精确字节写入应用本机内容寻址存储，用于正式导出时重新验证。项目移机、应用数据被清理或内容对象缺失后，需要重新选择原 XML。

## Emby 网络访问

只有用户配置并主动使用 Emby 功能时才发起请求。桌面版通过受限 Tauri 后端代理访问指定服务器；Web 开发版可能受到浏览器 CORS 限制。

## 分享前检查

项目文件、工程诊断和本机 benchmark 可能包含本地路径、稳定摘要或可关联同一数据集的信息。分享前应先检查内容；不要公开 token、账号、未授权媒体路径或原始评测数据。
