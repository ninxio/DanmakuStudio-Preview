# Danmaku Studio 用户指南

## 1. 先准备文件

一次项目需要：

- 至少一份最终观看的原片；
- 至少一份弹幕所对应的参考视频；
- 至少一份 Bilibili XML。

原片和参考视频可以是一对一、一部长参考视频对应多集原片，或多个参考视频对应多个原片。应用不要求你先切割视频。

## 2. 新建或打开项目

- 点击顶部“新建项目”开始空项目。
- 点击“打开项目”选择 `.danmaku-project.json`，旧 schema 会在内存中迁移；再次保存时写为当前格式。
- 页面底部状态栏会显示导入、匹配、保存和错误结果。

建议在导入和匹配完成后保存一次项目，以便日后恢复。

## 3. 素材页

### 原片素材

点击“批量导入原片素材”，一次选择多集视频。原片是最终输出 XML 要对齐的标准时间轴。

### 参考视频

点击“批量导入参考视频”。它只用于分析弹幕原时间轴，不会成为导出视频。

### 弹幕 XML

点击“批量导入弹幕 XML”。导入后，为每个 XML 选择它实际对应的参考视频。绑定错误会让后续匹配失去意义。

每个文件的格式、时长、路径状态放在“文件详情”中。只有出现问题时才需要展开。

### 素材断开

项目文件不嵌入视频。原文件被移动、重命名或换机后，素材会显示需要重新连接。选择同一文件重新连接即可；若内容身份不同，应用会拒绝把它当成原文件。

## 4. 智能匹配页

### 运行匹配

选择参考视频、原片和关联 XML，点击主要匹配动作。媒体分析可能需要 FFmpeg/FFprobe，并会在底部状态栏显示进度。

### 看懂结果

- **已匹配**：已得到可用时间关系。
- **需要复核**：多个候选接近，或检测到删减/额外内容。
- **可人工接管**：自动证据不足，但可以由你明确承担风险并手工调整。
- **已阻断**：素材、工具、媒体身份或验证条件不满足，不能继续假装成功。

结果里的四类时间段分别表示共同内容、参考独有、原片独有和暂时无法判断。不要把“参考独有”误当成原片要剪掉的内容；应用只会决定弹幕如何投影。

### A/B 试听复核

打开复核预览，在同一内容或差异边界来回试听参考和原片。只有真实播放、页面可见且媒体时间连续推进时，复核时长才会计入；拖动、暂停或后台停留不会伪造完成状态。

### 手动工具

普通项目不需要展开“手动补充或精修来源段”和“开发与验收工具”。只有自动结果不足、旧项目兼容或工程验证时使用。

## 5. 校准页

校准工作区由预览、弹幕覆盖、时间关系和所选对象参数组成。

### 自动排列

只有 XML、尚未放入时间轴时，点击“自动排列弹幕”。这会创建非破坏性片段，不改原 XML。

### 常用修复

展开“常用修复”：

- “整体提前 0.5 秒”或“整体延后 0.5 秒”适合全片固定错位。
- “从这里重新同步”在当前参考时间添加同步点，并填写对应原片时间。
- “这之后有版本差异”适合删减、额外片段或局部跳变；正负秒数决定后续映射如何变化。

所有动作都进入撤销/重做历史。顶部撤销和重做按钮可恢复。

### 单条弹幕

在时间轴或检查器选中弹幕后，可以禁用或做单条毫秒调整。禁用只影响导出，不删除原始条目。

## 6. 导出页

### 导出前检查

先处理红色阻断项。黄色提示不一定阻断，但应确认是否符合预期。常见阻断包括：

- 媒体需要重新连接；
- 时间轴片段引用了已删除 XML；
- 时间关系尚未满足可信导出条件；
- 没有为 XML 建立可投影到原片的来源段。

页面提供的修复按钮会真实修改项目，并进入历史；不会出现只改变提示、不改变数据的假操作。

### 正式分集导出

检查文件名和每集弹幕数量后，点击“导出全部分集 XML”。桌面版需要先在“设置 → 导出”选择默认文件夹。

成功后页面显示真实路径。已有同名文件时会自动采用新名字，不覆盖原文件。

### 兼容导出

“兼容导出方式（单集或旧项目）”保留单时间轴 XML 和传统按文件名分 P 合并。项目一旦包含目标原片或时间映射，这些旁路会被禁用，避免绕过分集映射导出错位 XML。

## 7. 与播放器一起使用

Danmaku Studio 只生成 XML。把导出的 XML 与原片放到播放器可以识别的位置，或按所用播放器的规则加载。播放器、Emby 和媒体库的命名要求不由本应用修改。

## 8. 建议的项目习惯

- 导入后、确认匹配后、完成校准后各保存一次项目。
- 不要在媒体分析过程中替换同路径文件。
- 导出后随机检查片头、片尾、删减点和一处中段。
- 保留原始 XML；应用生成的 XML 是新文件，不应代替来源备份。
