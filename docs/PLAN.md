# Danmaku Timeline Studio 实施计划

## 阶段1：基础工程

交付：

- 初始化 React + TypeScript + Vite + Tailwind + Tauri 2 工程。
- 配置 pnpm、Vitest、React Testing Library、Playwright、ESLint、Prettier。
- 创建基础布局、深色编辑器外壳和示例数据。
- 创建 `AGENTS.md`、`README.md`、架构和进度文档。

验收：

- `pnpm install` 可安装依赖。
- `pnpm dev` 可打开基础界面。
- 文档列出运行方式、限制和阶段计划。

## 阶段2：XML 领域逻辑

交付：

- Bilibili XML 解析、警告收集、序列化和导出验证。
- 保存完整 `p` 字段，解析已知字段，保留未知字段。
- 处理特殊字符、多语言、非法节点和大文件。

验收：

- XML 单元测试通过。
- 导出的 XML 可被重新导入。

## 阶段3：项目与资源管理

交付：

- 多 XML 导入、资源面板、分 P 自动排列。
- `.danmaku-project.json` 保存与打开。
- schema 版本检查和后续迁移接口。

验收：

- 可导入多个 XML，创建独立资源和片段。
- 保存后重新打开可恢复编辑状态。

## 阶段4：时间轴

交付：

- Canvas 2D 时间轴、标尺、播放头、视频轨、删减轨、片段轨、密度热力图、事件轨。
- 横向滚动、缩放、框选、选择、拖动片段和弹幕。
- 视口内绘制、二分查找、时间桶聚合。

验收：

- 5 万条合成弹幕下平移缩放无明显长时间卡死。
- 关键交互真实改变编辑状态。

## 阶段5：视频与弹幕预览

交付：

- `MediaAdapter` 抽象。
- `HtmlVideoMediaAdapter` 当前实现。
- `NativeMpvMediaAdapter` 占位接口。
- 视频和时间轴双向同步。
- 基础滚动、顶部、底部弹幕渲染。

验收：

- 浏览器可播放的 MP4/WebM 可预览。
- 弹幕开关、透明度、安全区可生效。

## 阶段6：删减映射

交付：

- 片段偏移、全局偏移、删减感知映射。
- `SyncAnchor` 和分段线性映射扩展点。
- `ManualAlignmentProvider` 与 proposal JSON 导入导出。

验收：

- 多个删减标记会累计影响后续弹幕最终时间。
- 候选锚点/删减点可预览并手动应用。

## 阶段7：编辑器完善

交付：

- 检查器、快捷键、撤销重做、导出摘要。
- 禁用/恢复弹幕、删减标记编辑、全局偏移编辑。
- 导出前摘要和重新解析验证。

验收：

- 指定操作可撤销和重做。
- 导出摘要数值可信。

## 阶段8：测试和视觉修复

交付：

- 单元测试、组件测试、E2E 流程。
- 1440x900 截图：空项目、导入项目、时间轴编辑、删减标记、导出对话框。
- README 最终补全。

验收：

- `pnpm build` 成功。
- `pnpm test` 通过。
- `pnpm test:e2e` 通过，或记录环境阻塞原因。
- 截图已生成并人工检查。
