# 方案存档

本目录保存已经讨论、但尚未全部实施的阶段性方案。它们用于回顾决策和恢复上下文，不代表当前实现，也不属于 Codex 每次开发必须读取的默认资料。

## 使用规则

- 日常开发只读取根目录 `AGENTS.md`、`progress.md`，再按任务需要读取 `docs/DEVELOPMENT.md` 或 `docs/ux-charter.md`。
- 只有开始对应主题、追溯历史决策或更新该方案时，才读取本目录中的文件。
- 方案实施后，在文件头更新状态，并把当前结论同步到 `progress.md`；详细过程保留在 Git 历史中。
- 不在本目录追加流水账、测试日志或大段命令输出。
