# C136：多视频批量导入与多对多自动匹配闭环

## 目标

让北极星场景真正可完成：用户一次导入 5 个原片、一次导入 1 个 B 站合集及其 XML，直接从项目素材中发起批量匹配，复核候选后得到 5 条可信来源段，最终按 5 个原片导出 XML；主要操作不超过 10 次。

本阶段必须同时解决：

1. 桌面端视频原生多选与持久本地路径导入；
2. 匹配页从单对单路径工具升级为项目素材关系工作台；
3. 长参考视频中的目标原片片段定位，以及 N 个参考与 M 个原片的批量候选；
4. 自动结果以候选存在，确认后写入 `danmakuSourceSegments` 和段内 `timingRules`，真实进入投影导出主链；
5. 候选、拒绝状态、证据和确认关系可保存、重开和撤销。

## UX 归置

- **素材页**：唯一文件导入入口。原片和 B 站参考各有原生批量导入按钮；桌面端一次选择多个文件，网页模式保留多文件 input 回退。
- **匹配页**：只引用项目内素材，不再要求重新选择视频路径。默认选择所有可用参考与原片，生成笛卡尔候选任务；显示待复核候选和已确认关系。
- **编辑页**：只做精细时间轴与单条修正，不承担素材配对。
- **导出页**：继续消费已确认来源段，不直接消费算法候选。

## 数据模型

确认态继续以 `DanmakuSourceSegment` 为唯一映射真相；它本身可以用多条边表达一对多、多对一和多对多。

schema 升级到 v9，新增持久化 `mediaMatchCandidates`：

- 稳定候选 ID 与批次 ID；
- `sourceMediaId`、`targetMediaId`；
- 来源开始/结束、目标起点；
- 段内删减修正规则；
- 置信度、诊断和原始 proposal；
- `pending` / `accepted` / `rejected`；
- 已生成 segment ID，用于幂等和撤销复核。

v8 → v9 迁移只补空候选数组；旧单一 `alignmentProposal` 作为兼容高级诊断保留，不猜测它属于哪一对素材。

## 自动匹配

1. 参考素材作为长时间轴，原片作为需要定位的目标。
2. 音频稀疏指纹先在长参考中定位目标区间；覆盖率按目标原片/候选区间计算，不按整条长参考计算。
3. 对已定位区间继续使用现有精对齐流程生成锚点和删减候选。
4. 输出携带绝对来源范围、目标范围和素材 ID 上下文。
5. 多组任务顺序执行，复用 Tauri 特征缓存；单组失败不丢失其他结果，可取消剩余任务。
6. 接受候选时，把删减候选转成 segment `timingRules`；不得写入与投影主链无关的全局 `cutMarkers`/`syncAnchors`。
7. 同一参考可接受到多个原片；多个参考也可接受到同一原片；不以文件名或列表顺序建立关系。

## 素材导入

- Tauri 原生 dialog 必须使用 `multiple: true`，统一支持 mp4/mkv/webm/mov/m4v/avi/flv/ts/m2ts。
- 新增批量本地路径 store action，一次历史事务创建全部 `localPath` 素材。
- 同角色、同规范化路径自动跳过，并报告成功/跳过数量。
- 新路径不能再把整批第一项当成唯一 `project.media` / `mediaBinding`。
- 浏览器回退仍可多选，但明确其重开后需要重连；桌面主路径保存重开后保持已连接。
- 全局拖放不得把视频静默猜成 B 站参考；视频角色必须在素材页明确。

## 匹配页交互

1. 顶部状态显示“已确认目标数 / 原片总数、待复核数”。
2. “自动匹配项目素材”默认勾选全部可用参考与原片；不可用素材就地说明需回素材页重连。
3. 发起前明确显示将运行多少组，不出现路径输入框。
4. 候选用结果语言呈现：`合集 48:12–72:40 → 第 3 集 00:00 起`。
5. 每个候选可调整来源起止和目标起点，并选择应用到该参考所绑定的 XML；支持接受或忽略。
6. 已确认关系按参考素材分 lane 展示；不同参考视频绝不共用同一时间标尺。
7. 手动来源段编辑作为补充入口，XML 选择后来源素材由绑定关系决定；目标起点与段内修正可见。
8. FFmpeg 参数、JSON、任务日志和旧单对单工具收进“高级诊断”。

## 一致性修复

- XML 绑定与来源段 `sourceMediaId` 不一致时阻止创建/更新和导出。
- 没有任何来源段的 XML 也计入未映射弹幕。
- 匹配进度不能因只匹配 1/5 个原片而显示完成。
- 删除素材时必须处理其待复核/已接受候选引用，不留下悬空 ID。
- 同名目标原片的导出文件名不得互相覆盖。
- 已知目标时长时，对超出目标范围的投影给出健康检查问题。

## 非目标

- 不剪切、转码、重封装或导出视频。
- 不下载 B 站视频或绕过授权。
- 不把视频内容写入项目文件。
- 不让低置信候选自动成为已确认关系。

## 执行顺序

5. 多素材一致性与投影健康检查；
6. 北极星走查、全量验证、release、提交与 checkpoint 标签。
