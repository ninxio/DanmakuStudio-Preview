# 故障排查

## 导入

### 视频拖入后还要确认角色

这是正常行为。应用不能从文件名可靠判断它是原片还是参考视频。批量任务建议使用素材页各自的导入按钮，桌面版还能保存真实本地路径供匹配与重连。

### XML 导入失败

确认文件是完整 Bilibili XML，并包含 `<i>` 根元素和 `<d p="...">` 弹幕条目。不要把 ASS、JSON 或网页内容改扩展名为 `.xml`。

### XML 已导入但不能匹配

在素材页为 XML 选择正确的“弹幕来源视频”。XML 与参考视频没有绑定时，应用不知道它属于哪条参考时间轴。

### 显示“需要重新连接”

项目记录的是媒体引用，不包含视频。原文件可能被移动、改名、替换或位于另一台电脑。使用重新连接选择原文件；内容不同会被拒绝。

## 预览

### MKV 没有画面或浏览器提示格式不支持

内置 HTML 预览主要支持 MP4/WebM。桌面版可在“设置 → 播放器与工具”配置 mpv 可执行文件，然后重新选择真实本地媒体。

### mpv 无法启动

检查配置是否指向真实 `mpv.exe`，而不是快捷方式或不存在的路径。关闭正在运行的旧 mpv 进程后重试，并确认安全软件没有阻止子进程。

### 预览能播但复核时长不增加

复核只记录页面可见、1 倍速、连续向前播放的有效区间。暂停、seek、切换来源、窗口进入后台或循环跳回不会计入。

## 智能匹配

### 提示找不到 FFmpeg/FFprobe

在“设置 → 播放器与工具”检查自动检测结果，或指定真实 `ffmpeg.exe` 和 `ffprobe.exe`。若刚修改系统 `PATH`，完全退出并重启应用。

### 一直是“需要复核”

这通常表示多个位置得分接近、存在版本差异，或素材质量不足。打开候选的 A/B 试听，确认共同内容和差异边界；不要仅凭百分比分数直接接受。

### 匹配任务取消后仍不可再次运行

等状态栏确认后台媒体进程已经安全退出。如果显示进程清理阻断，请完全退出应用，确认没有残留 FFmpeg/FFprobe/mpv 后重开。应用不会在无法确认清理完成时启动下一次重任务。

### NVIDIA/CUDA 没有启用

CUDA 是可选加速，不影响 CPU 正确路径。只有驱动、cuFFT 动态库和真实计算检测全部通过时才会显示可用；FFmpeg 能看到 NVIDIA 解码器不代表音频匹配已使用 GPU。

## 导出

### “导出全部分集 XML”不可点击

按按钮标题和导出前检查处理原因。最常见情况是：

- 还没有可导出的来源段；
- 时间关系尚未确认；
- 桌面版尚未设置默认导出文件夹；
- 当前运行在浏览器预览而不是 Tauri 桌面版；
- 媒体文件身份或原始 XML 收据无法重新验证。

### 为什么不能退回浏览器下载

正式分集导出必须在写盘前重新核对媒体、时间图、原始 XML 和项目快照。浏览器下载无法提供同样的本地身份与原子写入保证，因此会明确阻断，而不是静默降级。

### 导出的名字后面多了编号

目标目录已有同名文件。应用不会覆盖，因而自动选择可用名字。成功区会显示实际路径。

### 换机后不能直接导出旧项目

项目不携带安装级验证密钥、原始视频或本机 XML 内容对象。重新连接同一媒体、重新选择原 XML，并按提示重新完成复核。

## 项目

### 旧项目能否打开

当前 schema 会迁移旧项目。打开后先看状态栏和导出前检查，处理失效引用与媒体重连，再另存当前版本。

### 项目文件是否包含视频或密码

不包含视频。Emby 密码、访问 token、临时播放 URL 和安装级密钥不会写入项目文件。详情见 [隐私与本地数据](PRIVACY_AND_DATA.md)。

### 如何恢复以前的开发版本

开发者可用 Git 提交和 `checkpoint/...` 标签查看历史；命令见 [开发与恢复](DEVELOPMENT.md)。不要用 `git reset --hard` 清理普通工作区。

## 仍未解决

如果问题仍存在，请记录：

- 当前所在步骤和最后一个真实操作；
- 状态栏完整文字；
- 输入文件类型与数量（不要公开本地绝对路径、token 或受版权保护内容）；
- 能否在新空项目复现；
- 应用版本和 Windows 版本。
