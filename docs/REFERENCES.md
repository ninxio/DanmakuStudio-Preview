# 参考记录

本项目采用 clean-room 独立实现。未复制 GPL 项目源代码、类名、函数名或完整算法实现。

## 公开项目能力参考

- `danmubox/danmubox-develop`：参考其作为弹幕工具的功能边界，例如弹幕导入、管理和导出属于独立能力。
- `Poker-sang/DanmakuPlayer`：参考“弹幕播放/渲染器”这一产品能力，即需要在视频画面上叠加弹幕预览。
- `xyoye/DanDanPlayForAndroid`：参考“本地媒体 + 弹幕文件”工作流，以及弹幕与视频同步属于核心体验。

## 独立设计原则

- 时间轴编辑、片段、删减映射、撤销重做和项目文件格式均为本项目独立设计。
- XML 解析和序列化基于 Bilibili XML 公开数据形态独立实现。
- 不包含真实账号、Cookie、Token 或服务器地址。
