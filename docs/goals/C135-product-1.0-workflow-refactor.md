# C135：产品 1.0 动线重构与投影导出主线

## 目标

将应用从“功能堆积的工具面板”重构为符合 `docs/ux-charter.md` 四页动线的可交付 1.0 版本：

```
素材 → 匹配 → 编辑 → 导出
```

用户能沿一条清晰主线完成：导入多集原片 + 长参考视频 + XML → 标定来源段 → 按原片分集导出投影后的弹幕 XML。

## 本阶段交付

1. **工作流进度模型**（`workspaceProgress.ts`）：四页完成状态、阻断原因、推荐下一步，感知来源段投影结果。
2. **页面进度横幅**（`WorkspaceProgressBanner`）：素材/匹配/导出页顶部显示步骤进度与跳转引导。
3. **新手引导对齐四页动线**（`workflowOverview.ts` 重构）：阶段改为素材/匹配/编辑/导出，导出以投影分集为主路径。
4. **素材页收拢**：旧版单目标绑定与匹配评分折叠到「高级：兼容旧项目」；主路径只保留多媒体库 + XML 绑定。
5. **导出页层级**：「按原片分集导出」置顶为主路径；单文件/传统分 P 导出明确标注为次要方式。
6. **布局**：素材/匹配/导出页加宽至 `max-w-5xl`，减少信息挤压。

## 不在本阶段范围

- 一对多自动音频匹配（长视频自动切分到 N 个原片）
- AssetPanel 物理拆文件（后续 C136）
- 新增 schema 版本

## 验收

- [x] 空项目打开后，素材页横幅显示「先导入原片、参考视频和弹幕 XML」
- [x] 来源段 + 投影就绪后，导出页显示 N 个可导出分集预览
- [x] 新手引导四阶段与顶栏导航一致
- [x] 317 个自动化测试通过
- [ ] `verify:release` 通过并生成新安装包

## 北极星走查（手动）

1. 素材页：导入 2 个原片、1 个长参考视频、1 个 XML，绑定参考视频
2. 匹配页：创建 2 个正片来源段分别指向 2 个原片
3. 导出页：确认 2 集预览，点击「导出全部分集 XML」
4. 全程不需要在编辑页之外寻找隐藏入口
